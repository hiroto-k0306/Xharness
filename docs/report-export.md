# 静的 HTML 実行レポート

学習用に、保存済み会話とレシートをブラウザで読める単一 HTML に出力する。追加のモデル・ツール・フック実行はなく、元の会話やレシートも変更しない。

## 使い方

[出力サンプル HTML](examples/execution-report.html) を同梱。GitHubではソースが表示されるため、ファイルの「Download raw file」で保存し、ブラウザで開く。保存済みのマスク済み実録fixtureから生成した3件のレシートの例で、子エージェント・保存会話の別ファイルは含まない。新しいモデル通信は行っていない。

画面ではセッションの実行終了後、receipts の「HTML出力」を押し、保存先を選ぶ。親セッションに属する子エージェントもまとめて出力する。子の表示を選択していても出力対象は親セッション全体。既存ファイルへの上書きはできないため、新しいファイル名を選ぶ。

headless:

```powershell
pnpm build:headless
node dist/headless.js --report <sessionId> --output report.html
# fake の保存先を読む場合
node dist/headless.js --fake --report <sessionId> --output fake-report.html
```

`XHARNESS_HOME` が指定されていればその保存先を読む。CLI は保存中のセッションも読めるが、途中の記録になるため終了後に出力する。保存先の親ディレクトリは事前に用意する。閲覧は HTML をブラウザで開き、会話や入出力の項目を展開する。

## 内容と記録範囲

既定では日本語の見出しと操作説明で、LLM入力・応答を左右に並べる（狭い画面では縦並び）。ユーザーの依頼、追加の指示、ツール実行結果、LLMの返答・要求操作を表示する。2回目以降は前回と共通の履歴を折りたたみ、追加分を表示する。履歴が変わった場合は比較できない旨と最新メッセージを表示する。

systemの全文、ツールのスキーマ、識別子・メタデータは「詳細JSON・記録情報を確認」にまとめる。簡易表示は直近4メッセージ、本文ごと1200文字まで。全文は詳細欄に保持し、省略を明示する。未知の形式も詳細欄から確認できる。日本語化は見出し・操作説明で、プロンプトや返答本文の自動翻訳は行わない。表示のための追加LLM通信はない。

- STEP 1〜6 の役割説明。
- 親・子別の保存会話（ユーザー入力、依頼、ツール結果、応答）。
- 保存順のモデル呼び出し・ツール・権限・フック・圧縮・fallback の記録。
- system、履歴、ツール定義を含むモデル入力と応答（内部共通形式）。
- 保存時刻、所要時間、モデル、利用トークン（保存されている項目のみ）。

API 変換後の HTTP 本文、生 SSE、再試行ごとの通信、Web 要約・圧縮などの補助通信は網羅しない。STEP の時系列・通信の開始終了は保存レシートから復元せず、時刻・所要時間は保存値を表示する。親子の所属は保存フォルダから確定するが、個別 Task と子 ID の対応は未記録。fake の記録は通信があった証拠にはならない。

秘密値を再マスクし、認証フィールド・暗号化 reasoning・署名を伏せる。外部通信・スクリプトなし。会話・ソースコードはレポートに含まれる。入力を HTML として実行せず文字表示する。

読み込み上限はファイルごと16 MB、レシート1件2 MB・1万件、履歴1万件、子100件、全体32 MB（JSON文字数でも確認）。不正な行は除外件数を表示する。
