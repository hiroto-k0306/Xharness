# M2：スラッシュコマンドの体系

2026-10-03。DESIGN.md §26.2のM2を `codex/m3-m5-agent-features` で実装した。次はM4 → M5。同じブランチを使用する。実Claude / ChatGPT API通信なし。依存追加なし。

## 実装

- GUIの入力補完に `/clear` `/resume` `/model` `/cost` `/init` `/mode` `/stop` `/compact` `/mcp` と既存の巻き戻し・段階コマンドをまとめた。`/exit`はheadless専用。
- `/clear`は新しいセッションを作り、旧履歴を保持する。GUIは同じワークスペース・読み取り専用の区分を使い、隔離セッションなら新しいworktreeを作る。モデル・モードは通常の新規セッションの既定に従う。headlessは現在の作業フォルダ・モデル・モードで新しい会話を作る。
- `/resume`は保存済みのIDとタイトルを一覧表示し、`/resume <sessionId>`で既存会話を開く。GUIは履歴を用意してから選択状態を通知する。headlessは現在のMCP接続等を閉じ、選んだ会話のcwd・設定・モデル・履歴で初期化し直す。
- `/model`はモデル一覧を表示し、引数ありは従来の検証・変更処理を使う。
- `/cost`はM3の保存済みカウンタに基づく実通信／模擬通信の今ターン・セッション回数と、親・子の取得済みレシートの入力／出力トークン合計を表示する。金額・未取得の使用量は推測しない。headlessにもレシート保存を接続した。圧縮などレシートに使用量のない通信はトークン合計に含まれないが、M3の通信回数には含まれる。
- `/init`は作業フォルダのAGENTS.mdへ固定の日本語雛形を書き込む。`wx`で排他的に作成し、既存ファイルやリンクを上書きしない。読み取り専用・planでは作成せず、GUIは他の書き込みセッションが実行中でも拒否する。ユーザー自身のコマンドなのでLLMへ承認を求めず、LLM通信もしない。
- ユーザー定義は `<home>/commands/*.md`、プロジェクトは `<cwd>/.xharness/commands/*.md`。1階層の通常ファイルを読む。ファイル名は文字・数字・ハイフン・アンダースコアで、大文字小文字を区別する。空・1 MiB超・読めない定義・シンボリックリンクは除外する。ディレクトリのリンクも除外する。1件の不正が他のコマンドを止めない。
- 同名なら信頼済みプロジェクト側が優先する。組み込みと `mcp__` の名前は予約する。引数の `$&` 等もそのまま挿入し、展開を再帰させない。本文が `/clear` で始まっても通常のuserメッセージになる。
- プロジェクト側は信頼するまで一覧・展開の対象にならない。許可ルールのないプロジェクトでも定義があれば、通常の送信時にProjectSettingsの既存確認を出す。セッション承認はその会話だけ、「常に」はWorkspaceTrustへ保存する。headlessでは従来どおりGUIで保存した信頼を使う。未信頼・未定義のコマンドはエラーにしてLLMへ送らない。
- GUIの定義一覧は新規会話・再開・ready・送信開始・信頼承認で更新し、状態通知ではディスクを読まない。ファイル追加後はセッションを開き直すか通常の送信で補完を更新できる。本文は実行時に読み直す。
