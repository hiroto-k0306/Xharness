# H1：TodoWrite（軽量な進捗リスト）

## 実装

- `TodoWrite({todos: [{content, status}]})`を親・子・headlessのツール集合に追加。段階・権限モードによらず利用でき、セッション中の集合・順序を変えない。
- 毎回リスト全体を置き換える。空配列でクリア。空白だけのcontentや不正なstatusなどの形式違反は、固定の日本語の`invalid_args`を返す。件数・文字数の上限は設けず、複数のin_progressも受け付ける。ツール説明で同時に1件までを勧める。
- 外部への副作用を持たない履歴・表示用のツールとして、権限確認を常にallow。停止用のcontrolツールとは別に扱い、同じ応答の他の呼び出しを取り消さない。
- 状態の根拠は各エージェントの成功したTodoWriteの履歴。ツール入力に全文を保存し、各更新を会話内の日本語の進捗リスト（未着手・進行中・完了）で表示する。過去の更新はその時点の履歴として残す。再開時は保存済みのツール呼び出しと成功結果から復元する。実行前・失敗した呼び出しは通常のツール行として表示する。
- レシートに入力の全文と更新結果を記録し、詳細画面にも進捗リストを表示。表示内容はReactでエスケープし、画面・永続化には既存の秘密値マスクを適用する。
- 子のリストは子自身の履歴に保存。親の会話や進捗には混ぜず、親には子の最終回答だけ返す。子のレシートからその子のリストを確認できる。
- SubmitPlanやワークフロー状態とは独立。Todoをcompletedにしても、変更のレビュー要件・差分判定・作業完了条件を解除しない。
