HTMLを保存しブラウザで開いてください。すべて単独で閲覧できます。GitHubのファイルページでは「Download raw file」でダウンロードしてください。

基準HEAD `27262a3` と未コミットのランタイム修正から作成した配布物で検証。Codex CLI `0.162.0-alpha.20`、Claude SDK `0.3.293`、SDK同梱CLI `2.1.293`。詳細は[検証報告](../../../codex-prerelease-live-20261008.md)を参照してください。

通常workflowの会話レシートはハーネス側の処理とworkflow IDを記録し、公式基盤内部のモデル往復をすべて保存するものではありません。LLM呼出・モデル証跡・使用量・独立テスト・レビューは対応する詳細レポートを参照してください。レシートの6 STEP説明は従来出力の共通説明で、通常workflowの全工程の実測順序ではありません。

会話レシート末尾のLocalBrowserStopは撮影時の停止操作の記録（deny）で、実装失敗やモデル通信ではありません。拒否を消して成功に見せないため、そのまま収録しています。レビュー指摘は両方向とも0件で、修正サイクルは今回未検証です。

使用量のscopeはproviderごとに異なります。HTMLの「入力の既知合計」はcacheを含む正規化後の値で、検証報告の生のIn値とは定義が異なります。どちらも課金額やサブスク残量への換算ではありません。秘密値・認証情報・思考本文・実案件の履歴は含めず、合成課題の原本出力を収録しています。
