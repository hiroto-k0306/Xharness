# XHarness

Windows向けのコーディングエージェントです。公式Claude Agent SDK / Codex App Serverを使い、Claude Pro / Max、ChatGPT Plus / Proの正規認証と通常枠を確認します。APIキーや旧HTTP経路への自動切替は使いません。

この説明は2026-10-09のGUI/headless共通化後のソース仕様です。以前作成した配布物には今回の変更が入っているとは限りません。新ソースのWindows配布・インストール・実モデル通信は今回未検証です。配布版ごとのソースリビジョンとハッシュを確認してください。変更前の手順はソースリポジトリの [旧配布README](../Old/release-README-6370866.md) に保存しています（Old資料はexe配布物には同梱しません）。

## モデルの選択と最新世代

モデルは世代なしalias（opus/sonnet/haiku/astra/sol/luna）と別のeffortを選びます。画面はaliasと現在の完全IDを表示します。開始・許される安全再開・次の通信直前に現カタログで解決し、通信中は固定します。古い完全IDは明示された同じ会社/モデルfamilyの対応がある場合だけ将来の選択へ対応付け、過去の実行名・effort・計画・結果を書き換えません。

未知/競合、effort非対応、公式で利用不能なら停止し、別モデルやeffortへ黙って切り替えません。履歴と各通信のpolicy/実ID/変更有無を区別し、不確定な副作用を自動再送しません。この最新追従の変更は今回Windows/実モデル/GUI/配布で未確認です。fce9ebaのWindows48件成功は以前の限定試験です。前契約はソースリポジトリの [旧配布README-f7f7350](../Old/release-README-f7f7350.md)。

## 同梱ファイルと起動

| ファイル                     | 内容                                                                 |
| ---------------------------- | -------------------------------------------------------------------- |
| `XHarness-Setup-<版>.exe`    | ユーザーごとのインストーラ。インストール後はスタートメニューから起動 |
| `XHarness-<版>-portable.exe` | インストール不要のポータブル版。任意の場所に置いて起動               |
| `README.md`                  | この説明                                                             |
| `SHA256SUMS.txt`             | 配布ファイルのハッシュ                                               |

どちらか一方を使えば十分です。個人利用を前提とした未署名のアプリです。ポータブル版は起動時に一時フォルダーへ展開します。

Windows 10 / 11 x64、PowerShell 7、公式側でログイン済みの利用可能なサブスクリプションが必要です。リポジトリ操作にはGitを使います。Codex接続は公式workflowパネルで実行ファイルの参照先を確認します。パス設定だけでは認証・利用枠が確認できたことにはなりません。

ログイン・認証の更新は公式側の手順で行います。XHarness内の旧「認証・更新を許可」や自前の資格情報読み取り・更新は使いません。認証・枠・選択モデルが利用できない場合は理由付きで停止し、別モデル・別会社・追加課金経路へ自動変更しません。質問は同じ会社の接続だけで送れますが、作業には実装と別会社レビューのため両社の利用可能な接続が必要です。

## 質問・作業の進め方

1. タイトルバーのフォルダー選択で作業場所を開き、セッションを作ります。既存worktreeを使う場合はその場所で実行します。
2. 入力欄にテキストで依頼し、Enterで送信します。Shift+Enterは改行、モデル・effortは画面で選びます。
3. 同じ会社のHaiku / Lunaが質問か作業かを判別します。質問なら回答して終了します。作業なら選択メインモデルが公式ツールで探索し、単一課題の計画を提案します。
4. 実行場所・変更候補・検証方針を確認して計画を承認します。承認後は選択フォルダーへ直接編集し、公式モデルがテストを選択・実行・報告します。事前の既存テスト指定やcleanなGit状態は必須ではありません。
5. 開始時との固定差分を別会社がレビューします。失敗報告や重大指摘がある場合は最大2回修正します。

モデルのテスト実行報告と、ハーネスによる独立テストは別です。テスト未実施でもレビュー条件を満たせば完了する場合があり、未テストと表示します。自動コミット・変更の自動巻き戻しは行いません。既存編集の保全を指示・比較しますが、すべての副作用を復元する保証はありません。

操作確認にはコマンド全文・作業場所等を表示します。「今回の操作だけ許可」「拒否」「このフローのみ許可」を選べます。自動モードも計画承認が必要で、承認後の現在フローだけの操作許可です。許可は終了・停止・再起動で失効し、禁止操作・sandbox・network制限を解除しません。承認待ちは工程の120秒制限から除外します。10分以内に操作確認へ回答がなければ停止します。

停止は停止ボタン、または `/stop` を使います。Escは実行停止には使いません。停止・失敗・再起動後に作業を自動再送・再開しません。状態と差分を確認し、新しい指示で進めてください。

## 対応しない旧操作と保存履歴

GUIの通常入力はテキストのみです。旧slash補完・画像添付・旧workflow段階変更・MCP操作は理由を表示して無効化します。旧Web/MCP・子エージェント委託・予約・画像送信・巻き戻し等の独自ツールを公式モデルへ公開しません。保存された旧会話・MCP状態・レシートは閲覧できるものがありますが、旧操作を実行する入口ではありません。

手動のスキル管理やプロジェクトメモリ等の画面・過去記録が残っていても、公式モデルが旧ツールを利用できる意味ではありません。公式経路に適用できない権限ルール・フック・通信回数上限等が設定されている場合は、無視せず停止することがあります。

会話やレシートのHTML出力は履歴の閲覧・共有用です。出力のために追加のモデル通信は行いません。ソースコードや依頼文を含み得るため、共有前に内容を確認してください。公式workflowの入力・応答・公開イベントは保存上限・欠測を表示し、非公開思考・内部の全HTTP往復を記録するものではありません。

## 保存・更新・通信なしの確認

設定と履歴は既定で `%USERPROFILE%\.xharness` に保存します。`XHARNESS_HOME` で保存先を指定できます。同じ保存先へGUI/headlessを同時に書き込めません。既存の設定・履歴・認証ファイルを一括削除・移行しません。保存モデルが無効なら、最新モデルへ読み替えず理由付きで停止します。

`--fake` は通信なしの模擬動作確認で、既定の保存先を `%USERPROFILE%\.xharness-fake` に分けます。実アプリ・公式認証・sandboxの成功を証明するものではありません。

```powershell
.\XHarness-<版>-portable.exe --fake
```

XHarnessアプリ本体の新しい配布版は手動で更新します。Claude公式ランタイムの互換範囲内の管理更新と、アプリ本体の更新は別です。旧配布版と新ソース版を取り違えないでください。アンインストール後も設定・履歴は残ります。

Store版pwsh、他PC、今回の新ソースの配布、長時間・取消・再起動を伴う実通信は未確認です。コマンド準備に失敗した場合は接続先・公式CLI・Node/pwshの実行環境を確認し、sandboxやOS権限を緩和して代用しないでください。

## Headless

開発用のheadlessもGUIと同じ公式サービスを使います。`pnpm headless -- --help`、またはビルド済みの `node dist/headless.js --help` で引数を確認できます。exe配布物にheadless用Node/ソース一式が同梱されるという意味ではありません。

端末操作は `/help`、`/exit`、`/stop`、`/model`、`/mode`、`/resume`、`/clear`、`/history`、`/workflow` に限定します。計画・操作承認はTTYでのみ受け付け、非対話入力で承認が必要なら停止します。旧履歴は閲覧用で公式へ自動転送しません。`--report` / `--replay` は読み取り専用です。
