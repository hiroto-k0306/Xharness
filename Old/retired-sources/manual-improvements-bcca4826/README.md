# 廃止した手動改善版比較（実行対象外）

ユーザーが不要とした手動の指示・スキル・メモリ版比較、評価ケース登録、モデル候補比較、採用・復帰の専用ソースを保存します。通常の作業依頼・レビュー・修正、実行記録、将来のモデル履歴評価feedbackとは別機能です。

出典は `bcca4826` の完全SHAを記した [manifest.tsv](manifest.tsv) です。22件を移動し、共通コードを残す3件の旧入口をスナップショット保存しました。保存バイト列はgit blobそのままで、末尾 `.txt` により登録・import・ビルド・テスト探索へ復活させません。原本内のimportと実行手順は当時の表記です。

比較DB、会話、workflow、receipts、skills、memory、ユーザーデータは移動・削除・書換していません。共有テスト用の会話作成fixtureは手動比較メソッドを外した `official-session.fixture.ts` として残し、受渡し・ローカルブラウザーのテストを保護します。quota観測の `candidate-quota.ts` とその共有型は通常turn-eventsにも依存があるため維持します。

現行仕様は [SPEC.md](../../../SPEC.md)、設計は [DESIGN.md](../../../DESIGN.md)。旧IPCは現行parserで拒否し、古い直接callerにも廃止理由を返します。この保存庫を現役モデル機能・検証成功と扱わないでください。
