# XHarness 紹介資料

2026-10-08作成。実画面を使った12枚の日本語紹介資料です。

- [PowerPoint](XHarness-introduction-final.pptx)：見出しと説明文を編集できます。
- [HTMLプレビュー](XHarness-preview.html)：PowerPointがない環境でも、ブラウザでオフライン閲覧できます。

## 開き方

GitHub上ではHTMLを直接スライド表示しません。ファイルページの「Download raw file」でHTMLを保存し、ブラウザで開いてください。リポジトリを取得した場合は、このフォルダーのHTMLを直接開けます。

HTMLはスライド画像を内蔵しています。HTML単体でも閲覧できますが、画面上の「PowerPoint」リンクも使う場合は、PPTXを同じフォルダーへ保存してください。

「スライド表示」で1枚ずつ、「一覧表示」で縦に並べて表示します。左右キーと番号ボタンで移動できます。「全画面」やブラウザの印刷も利用できます。

## 資料の範囲

現行の[仕様書](../../../SPEC.md)と[実通信検証記録](../../app-live-validation-20261008.md)に基づいています。画面は保存済みのテスト用実画面で、旧検証版の文言やモデル表示が含まれます。通常入力の公式ワークフローと拡張機能の対応経路は区別しています。

紹介する実通信結果はc998a30版の合成課題の記録です。最新版の全環境やHaiku 5.5での実通信成功を意味しません。PowerPoint本体での描画は未確認です。[作成・検証記録](../../introduction-material-20261008.md)も参照してください。
