# XHarness 紹介資料

2026-10-08再撮影版。7枚構成を保ち、撮り直した通常会話・別会社レビュー・LoopFlowの実画面へ更新した日本語紹介資料です。

- [PowerPoint](XHarness-introduction-final.pptx)：見出しと説明文を編集できます。
- [HTMLプレビュー](XHarness-preview.html)：PowerPointがない環境でも、ブラウザでオフライン閲覧できます。
- [実通信のレシート・詳細レポート](receipts/README.md)：今回の合成課題の記録をブラウザで読めます。

## 開き方

GitHub上ではHTMLを直接スライド表示しません。ファイルページの「Download raw file」でHTMLを保存し、ブラウザで開いてください。リポジトリを取得した場合は、このフォルダーのHTMLを直接開けます。

HTMLは最終PPTXを描画した7枚と説明文を内蔵しています。HTML単体でも閲覧できますが、画面上の「PowerPoint」リンクも使う場合は、PPTXを同じフォルダーへ保存してください。

「スライド表示」で1枚ずつ、「一覧表示」で縦に並べて表示します。左右キーと番号ボタンで移動できます。「全画面」やブラウザの印刷も利用できます。

## 紹介する特徴

- ClaudeとCodexのサブスクリプションを一つの作業画面で利用
- 実装した会社とは別会社のモデルによるレビュー
- AIの通信とハーネスの処理を見分けるLoopFlow
- モデル入出力とSTEPを持ち出せる静的HTMLレポート
- 同じプロジェクトの会話間で、確定した結果を受け渡し
- 利用枠待ちを保存し、明示的に有効化したタスクを再開
- 委託元と子エージェントの入力・応答を、一つの記録から追跡

現行の[仕様書](../../../SPEC.md)に基づき、各機能の対象範囲はスライド内で短く説明しています。一般的な機能や検証実績の紹介は戻していません。元のまとめページは、親子の委託関係が見える実際のHTMLレポート画面に置き換えています。

1〜3枚目はCodex CLI 0.162.0-alpha.20・Claude SDK 0.3.293を使用した合成課題の実アプリ画面です。基準HEAD 27262a3と未コミット修正から作成したv3配布物で撮影しました。別アプリのゲーム表示・Windowsライセンス認証の透かしは写っていません。LoopFlowは通常workflowの担当と工程を表示します。公式基盤内部の全往復を表示するものではありません。

4〜7枚目は旧経路の既存デモ・模擬画面です。HTMLレポートはリポジトリ内の[デモ出力](../../examples/execution-report.html)です。今回の通常workflowでは結果受け渡しが拒否されたため、5枚目に利用不可と明記しました。枠待ち再開と子エージェントの記録例も旧経路の機能で、枠待ちの画面例は取消状態です。これらを現在の通常利用の成功例として説明しないでください。

画像は内容を変更せず必要な部分だけ切り出しています。今回、Codex実装・独立テスト・Haiku 5.5レビューと、Claude Opus 5.5実装・独立テスト・Codexレビューが完了しました。質問も両社各1回で終了。修正サイクルは指摘0件のため今回未検証です。[今回の実通信記録](../../codex-prerelease-live-20261008.md)と[以前の記録](../../loopflow-live-20261008.md)を区別してください。
