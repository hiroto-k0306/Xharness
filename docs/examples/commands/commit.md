今回の変更をコミットするための確認と提案をしてください。

追加条件（通常の文章として扱い、シェルコマンドには展開しない）：
$ARGUMENTS

1. 現在のブランチと git status --short、ステージ済み・未ステージの差分を確認する。既存のユーザー変更と今回の作業を混ぜない。秘密情報を含むファイルは表示・ステージしない。
2. 今回の対象ファイルと必要な検証を確認し、未実施・失敗した検証を明記する。
3. ステージするファイルの一覧と、日本語のコミットメッセージを提案する。git add は明示したファイルだけを対象にし、git add . は使わない。
4. この呼び出しでは確認・提案までとする。ユーザーが対象とメッセージを承認してから、別の入力で実行する。実行時も git diff --cached を確認し、承認対象以外が含まれる場合は止める。
5. push、PR作成、merge、既存コミットのamend、履歴の書き換えは行わない。
