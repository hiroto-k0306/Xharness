SDKの失敗subtypeを固定のエラー分類へ変換し、画面・履歴要約・HTMLに日本語の停止理由を表示する。SDKの生エラー本文、秘密、思考本文は保存しない。既存の `failed` 記録は、保存済み診断が `error_max_turns` と示す場合のみ説明する。保存履歴は書き換えない。
