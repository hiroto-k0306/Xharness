SEE THE HARNESS

LoopFlowで、AIの動きとアプリの処理を見分ける

会話の文章だけでは見えない、一周の流れを表示。

文脈の組み立て、モデル通信、ツール要求、
権限判定、実行、記録をSTEPで追えます。

「AIが答えた部分」と
「ハーネスが動かした部分」が分かります。

TranscriptとLoopFlowを切り替えて表示。03
PORTABLE EXECUTION STORY

処理の中身を、HTMLで持ち出す

アプリを閉じても、AIが何を受け取ったかを読める。

親・子の会話とSTEPを、一つの静的HTMLへ。
モデルに渡したsystem・履歴・ツール定義と、
返ってきた応答を保存範囲内でたどれます。

LLM通信は色で強調。ブラウザだけで閲覧できます。

モデルに渡したもの

system / 履歴 / ツール定義

モデルから返ったもの

応答 / ツール要求

ハーネスが行ったこと

権限判定 / 実行 / 記録

レポートの出力・閲覧でモデルを再実行しません。04
EXPLICIT RESULT HANDOFF

完了した結果を、同じプロジェクトの別会話へ

調査の結論を、そのまま次の仕事の参考に。

確定済みの最終回答を選び、宛先の会話へ受け渡し。
出典と受け渡す本文を確認できます。

受信だけではAIは動きません。
次の会話で、自分の依頼と一緒に使えます。

会話A

調査・方針の結論

結果の受け渡し

出典と本文を確認

会話B

結論を参考に次の依頼

会話の権限や認証情報を移す機能ではありません。05
OPT-IN QUOTA RESUME

利用枠を待ち、同じタスクから再開する

枠切れのたびに、依頼を入力し直さなくてよい。

観測した回復時刻をもとに、枠待ちを保存。
対象のタスクだけ、自動再開を有効にできます。
元の依頼を重ねて追加せず、保存した会話から続行。

枠待ちを表示

次回確認 / 期限 / 試行数
