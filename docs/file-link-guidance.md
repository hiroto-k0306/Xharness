# ファイル案内のアプリ共通仕様（2026-10-04）

ユーザーの「毎回リンクにして」「アプリ仕様にしてほしい」に対応。AGENTS.md だけの指示では別ワークスペースやメモリ無効時に適用されないため、DESIGN.md §14.2 とアプリ実装に組み込んだ。

## 実装

- `src/main/core/output-guidance.ts` の共通規則を main の `systemPrompt` と `ChildRunner` の system に含める（更新前の既存会話は下記の互換対応で除外）。AGENTS.md がなくても、カスタムメモリや空の memoryFiles、scratch、worker・reviewer・explorer で有効。
- ファイル・成果物・インストーラー・フォルダーの案内には明示 Markdown リンクを付ける。絶対 `file:///D:/...`、フォルダー末尾 `/`、パス区分の特殊文字のエンコード、実在する最新成果物の確認を指示。コード例のパスは対象外。秘密値をリンクに含めない。
- `TextLinks` は明示 Markdown のドライブ絶対リンク `D:/...` 等も `normalizeFileLink` で file URL に補正する。日本語・空白・特殊文字をエンコードし、既存エスケープは二重化しない。不正エンコード、dot segment、エンコードされた区切り、制御文字は補正しない。
- 生パス・コード・画像・相対リンク・UNC は自動リンク化しない。HTTPS と既存の明示 file URL は従来どおり扱う。main の URL・実体・ドライブ検証、ユーザークリックと毎回のネイティブ確認、preload の境界は変更しない。
- 書式の共通指示と明示リンクの補正であり、モデルが必ず規則を守る保証や、任意の場所を開ける保証ではない。ネットワークドライブ等は既存の main 検証で拒否される。
