# 静的 HTML 実行レポート

学習用に、保存済み会話とレシートをブラウザで読める単一 HTML に出力する。追加のモデル・ツール・フック実行はなく、元の会話やレシートも変更しない。

## 使い方

[出力サンプル HTML](examples/execution-report.html) を同梱。GitHubではソースが表示されるため、ファイルの「Download raw file」で保存し、ブラウザで開く。FakeProviderと実際のAgent Loop・ChildRunnerを実行して生成した全経過のデモ。全6STEP、再試行、Read、検証エラー、権限拒否、子への委託を含む。LLMは模擬応答で、実API通信・資格情報の読み取りは行っていない。

画面ではセッションの実行終了後、receipts の「HTML出力」を押し、保存先を選ぶ。親セッションに属する子エージェントもまとめて出力する。子の表示を選択していても出力対象は親セッション全体。既存ファイルへの上書きはできないため、新しいファイル名を選ぶ。

headless:

```powershell
pnpm build:headless
node dist/headless.js --report <sessionId> --output report.html
# fake の保存先を読む場合
node dist/headless.js --fake --report <sessionId> --output fake-report.html
```

`XHARNESS_HOME` が指定されていればその保存先を読む。CLI は保存中のセッションも読めるが、途中の記録になるため終了後に出力する。保存先の親ディレクトリは事前に用意する。閲覧は HTML をブラウザで開き、会話や入出力の項目を展開する。

## 内容と記録範囲

全レシートを「処理・入力・出力・詳細」の同じカード形式で表示する。入力・出力を左右に並べる（狭い画面では縦並び）。Claude/Codex のモデル呼び出し記録だけ紫の背景と左線、LLMラベルで強調する。他の記録は通常色とハーネスラベル。未保存の入出力は未記録と表示する。補助通信の有無は推測しない。

日本語の見出しと操作説明で、ユーザーの依頼、追加の指示、ツール実行結果、LLMの返答・要求操作を表示する。2回目以降は前回と共通の履歴を折りたたみ、追加分を表示する。履歴が変わった場合は比較できない旨と最新メッセージを表示する。

systemの全文、ツールのスキーマ、識別子・メタデータは「詳細」にまとめる。簡易表示は直近4メッセージ、本文ごと1200文字まで。全文は詳細欄に保持し、省略を明示する。未知の形式も詳細欄から確認できる。日本語化は見出し・操作説明で、プロンプトや返答本文の自動翻訳は行わない。表示のための追加LLM通信はない。

- STEP 1〜6 の実行時系列と、開始・終了、検証・権限・実行・次の処理の結果。
- 親・子別の保存会話（ユーザー入力、依頼、ツール結果、応答）。
- 保存順のモデル呼び出し・ツール・権限・フック・圧縮・fallback の記録。
- system、履歴、ツール定義を含む入力の簡易表示と、Adapterでの送信本文・受信SSE・組み立て後の応答。
- 保存時刻、所要時間、モデル、利用トークン（保存されている項目のみ）。

新しい実行は `traces/<親sessionId>.jsonl` に開始・終了を保存する。親子共通の開始順で表示し、委託元リンク、tool call ID、子IDで対応を確認できる。終了記録なしも表示する。未実行のSTEPは作らない。LLM詳細の送信本文はfetchに渡したJSONそのもので、ヘッダは保存しない。受信SSEはデコード前のevent/dataを保存する。SSEの空行・コメント・改行形式、HTTPエラー本文、未受信・未解析の断片は対象外。再試行、通常会話、圧縮、Webの補助通信、子の通信も同じ実行スコープで追跡する。

表示番号はSTEP番号・従来のレシート番号とは別。トレースがあれば従来レシートは補足に折りたたむ。導入前の履歴は従来の表示を維持し、欠番や未保存の処理は補完しない。模擬呼び出しは「LLM模擬・実通信なし」と明示する。

サンプルの再生成（新しい出力ファイル名を指定）：

```powershell
pnpm report:demo .out/new-demo.html
```

`.out/report-demo-<UUID>/` に通信なしの実行記録と作業ファイルを作り、HTMLへ出力する。既存HTMLは上書きしない。

秘密値を再マスクし、認証フィールド・暗号化 reasoning・署名を伏せる。外部通信・スクリプトなし。会話・ソースコードはレポートに含まれる。入力を HTML として実行せず文字表示する。

読み込み上限はファイルごと16 MB、レシート1件2 MB・1万件、履歴1万件、子100件、全体32 MB（JSON文字数でも確認）。トレースは1ファイル32 MB・2万行まで。受信イベントは1通信80万文字、保存1行100万文字までで、省略を明示する。不正な行は除外件数を表示する。
